# 🌐 DevPortfolio — Modern Engineering Portfolio & Interactive Showcase

> A sleek, high-performance developer portfolio website engineered with Tailwind CSS, vanilla JavaScript, and interactive HTML5 Canvas physics animations — presenting projects, technical skills, and experience with modern UI aesthetics.

## 🚀 Features

- **Interactive Constellation Canvas** — Custom 2D particle canvas that reacts to user mouse movements and clicks with ambient physics.
- **Dynamic Role Typewriter** — Smooth typing effect highlighting Full Stack, AI, and Cloud engineering roles.
- **Bento Grid Architecture** — Clean, modular card layout showcasing projects, tech stack badges, and career timeline.
- **Project Category Filters** — Instant client-side filtering between AI/LLM, Full-Stack, and Data Science projects.
- **One-Click Resume Download** — Direct download link to the latest ATS-optimized resume.

## ⚡ Quick Start

```bash
git clone https://github.com/Rushi-code1/portfolio2.git
cd portfolio2

# Run with any static server or Python:
python -m http.server 8000
```

Open `http://localhost:8000` to view the live site.
